# ASSEMBLY

Turn shared taste into an event worth gathering for.

A cultural production product that combines Qloo-informed discovery with verified venue constraints, audience interest, and operational coordination.

**Status:** repository initialized; implementation is being planned. There is no deployed application or measured product result yet.

## Product direction

Audience discovery, feasible event concepts, interest collection, operator approvals, and production execution.

Qloo will provide cultural-affinity evidence. Explicit user choices, operational facts, and independent evaluation will determine whether the proposed outcomes are useful and achievable.

## Development

This is an independent project for the [Qloo Agentic Hackathon](https://qloo.devpost.com/). Runnable setup instructions, environment examples, architecture documentation, and the public demo URL will be added with the implementation.

Implementation status and evidence will be documented honestly as features ship. Synthetic demonstration data and live integrations will be clearly distinguished.
